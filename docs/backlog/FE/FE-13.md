# FE-13: Admin manual sync control

Button on Overview (or header) for `role === admin` only. Calls `POST /api/v1/sync`, then poll `GET /api/v1/sync/status`. Viewer sees freshness only.

## In scope

- Admin: "Refresh data" / "Sync now". Pending state. 409 copy: sync already running.
- After success, refetch dashboard summary/trend/errors.
- Viewer: no button.
- Do not imply the dashboard is now real-time.

## Out of scope

- Backend. Sync on every page load. Viewer trigger.

## Frozen contract
