# FE-03: Login page BRI visual pass

Human-selected visual pass on the existing login route. Behavior stays FE-01.

## In scope

- Wire Inter as the UI sans font (`next/font/google` Inter, latin). Apply on the root layout if that is the only way to load Inter once; do not restyle the dashboard beyond inheriting Inter and semantic tokens.
- Copy BRI CSS variables from `docs/design/bri-tokens.css` into `frontend/app/globals.css`.
- Map shadcn semantic tokens for light theme at least:
  - `--primary` / button: `--bri-primary-cakrawala-main` (`#307fe2`), hover `--bri-primary-cakrawala-600`
  - `--primary-foreground`: `--bri-white-main`
  - `--background`: `--bri-black-100` (`#f5f7fb`)
  - `--foreground` / body text: `--bri-black-main` (`#181c21`)
  - `--muted` / `--border`: `--bri-black-200` / `--bri-black-300`
  - `--muted-foreground`: `--bri-black-700`
  - `--destructive` (login error): `--bri-red-main`
  - `--card`: `--bri-white-main`
- Restyle `frontend/app/(auth)/login/page.tsx` and `frontend/components/login-form.tsx` into a dense internal-bank login: centered card on the cool gray background, clear hierarchy (product name RPMP, title, helper text, form, primary submit).
- Keep FE-01 behavior: Employee ID + password, pending, `invalid_credentials` copy, cookie credentials, redirect if already authenticated.
- Update login tests if class names or copy wrappers change. Do not weaken assertions on errors or submit.

## Out of scope

- Dashboard layout, KPI cards, sidebar, or `(protected)` chrome (later card).
- New routes, new auth API fields, SSO, remember-me, logo asset unless a file already exists in the repo.
- New UI kits (MUI, Chakra). Stay on existing shadcn Button/Input/Label + Tailwind.
- Backend files.
- Dark mode (do not invent a BRI dark theme in this card).
- Pixel-perfect recreation of a missing screenshot. Palette + Inter + the mapping above are the spec.

## Visual rules

- Font: Inter for UI text. No Arial as the primary sans after this card.
- Primary CTA is Cakrawala blue, not black.
- Error text uses BRI red, not a generic orange.
- Mentari / neon / BRIVA / BRIZZI are available as tokens but do not paint the login card in neon unless used as a thin accent (for example a 4px Cakrawala bar). Default: restrained gray canvas + white card + one primary button.
- Copy stays English as on the current page unless you only fix grammar. Do not add Orchestrator jargon.
