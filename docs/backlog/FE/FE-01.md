## Frozen contract

Submit:

```json
{
  "employee_id": "12345678",
  "password": "user supplied secret"
}
```

`POST /api/v1/auth/login` and `GET /api/v1/auth/me` return:

```json
{
  "user": {
    "id": "018f5f71-9cb9-7a61-97e7-d8f33f12b821",
    "employee_id": "12345678",
    "display_name": "Example Viewer",
    "role": "viewer"
  }
}
```

The browser receives `rpmp_access` as an httpOnly cookie. Frontend JavaScript must not read or store it. Client requests use credentials. Errors use:

```json
{
  "code": "invalid_credentials",
  "message": "Employee ID or password is incorrect."
}
```
