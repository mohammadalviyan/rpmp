# FE-04: Dashboard shell and BRI layout

Styling and layout only for Overview. Copy **structure** from `docs/design/dashboard-layout-reference.png`. Colors from `docs/design/bri-tokens.css` (same mapping as FE-03). Do not copy the mock's dark orange theme, fake KPIs, or extra products (Email, Generate Report).

Layout reference: live sample app (often `http://localhost:8080` on the designer's machine) plus `docs/design/dashboard-layout-reference.png`. That sample is not the RPMP API.

RPMP UI to implement and click is Next.js, usually `http://localhost:3000/dashboard`. RPMP Go API is whatever `RPMP_ADDR` is (often `:8080` too, which collides with the sample; stop the sample or move one port before running both).

## In scope

- Protected shell: left sidebar + top header + main, like the reference.
- Sidebar: product mark **RPMP** (not "RPA Automation Reporting" as a second product). Nav: **Overview** (current, `/dashboard`). **Use Cases** visible but not a real page: render as disabled or `aria-disabled` with no fake route. Do not add Email, Report History, User Management, or theme toggle as working features.
- Header: title **Overview**, subtitle about monitoring summary, signed-in `display_name` and `role` from `GET /api/v1/auth/me`. Optional search input **disabled** (no use-case search API yet). No notification fake badge.
- KPI row: the **five** BE-02 fields only (Total Use Cases, Active Use Cases, Execution Volume, Success Rate, Failed Executions). Do not invent Unattended / Attended / Report Sent / "+3 this month".
- Bottom row: line chart from `GET /api/v1/dashboard/execution-trend` (success vs failure). Donut or simple distribution from `GET /api/v1/dashboard/errors`. Use BRI Cakrawala for success/primary, BRI red or black-500 for failure. Inter already from FE-03.
- Reuse shadcn + Tailwind. A small chart library is allowed (for example Recharts) if tests still pass. Compute nothing the API already computed.
- Logout control somewhere in the header or sidebar footer (existing logout endpoint). Keep cookie httpOnly.
- Verify in browser against local Next + API after implementation. Update component tests.

## Out of scope

- Dark-orange mock theme. Light BRI canvas (`--bri-black-100`, white cards, Cakrawala active nav).
- New backend contracts beyond BE-04.
- Health score, SLA, real Orchestrator, use case list page.
- Pixel-perfect clone of every icon in the PNG.

## Layout mapping

| Mock | RPMP |
| --- | --- |
| Total Use Case | `kpis.total_use_cases` |
| Success Rate | `kpis.success_rate` (`N/A` if null) |
| Total Issue | `kpis.failed_executions` |

| Success vs failed chart | `execution-trend` points |
| Error A / Error B donut | `errors.groups` labels from API |
