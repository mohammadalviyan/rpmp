# BE-06: cmd/sync from approved interim CSV

Copy aggregate source rows into RPMP tables. The approved interim mode reads CSV because `RPMP_SOURCE_DATABASE_URL` is firewalled. Live read-only source Postgres remains pending.

## Source inventory

`docs/report/DataSourceOrchestrator.csv` is authoritative and has 213 data rows. Its exact columns are:

`ProcessId, ProcessName, PackageName, EnvironmentName, FullyQualifiedName, CountExecuting, CountPending, CountSuspended, CountResumed, CountSuccessful, CountErrors, CountStopped, AverageDurationInSeconds, AveragePendingTimeInSeconds, TotalRows, EntityId`

`docs/report/FinalReportGoals.csv` is incomplete reference material and is not ingested.

## In scope

- `cmd/sync`: `RPMP_SOURCE_CSV_PATH` and `RPMP_DATABASE_URL` are required in interim CSV mode. `RPMP_SOURCE_DATABASE_URL` is not required for this mode.
- Advisory lock so two syncs cannot run.
- CSV adapter reads source → domain → repo upserts. Vendor CSV fields stay inside `internal/adapter`.
- Group use cases by `FullyQualifiedName`, use the full value as the name, and mark all listed use cases active.
- Retain all source process rows, including zero-activity rows. Store aggregate counts without synthesizing executions.
- Store successful, error, and stopped counts separately. The existing failure measure is `error + stopped`.
- Store `imported_at`; the reporting period is unknown.
- Idempotent snapshot publication by stable content hash.
- Write `sync_runs` running → success/failure.
- CLI exit 0 on success, non-zero on failure. Log counts, not passwords or full source rows.
- Tests: inline CSV adapter fixtures and RPMP repository integration checks.

## Out of scope

- Changing dashboard JSON. HTTP POST sync (BE-08). Frontend. Swagger. Live source Postgres acceptance.

## Frozen contract

None for HTTP. Sync must fill tables so BE-07 can compute the same metrics as the stub grouping (success vs failure).

## Acceptance

- [ ] `go run ./cmd/sync` against live local source + RPMP DSNs completes and inserts `sync_runs` (pending firewall access).
