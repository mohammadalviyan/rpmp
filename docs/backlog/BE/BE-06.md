# BE-06: cmd/sync from local source Postgres

Copy rows from a **read-only** source database into RPMP tables. Map vendor fields in `internal/adapter` only.

## Blocker before coding SQL

Document source tables/columns in this card or `docs/plans/LOCAL_DB_SYNC_2026-09-09.md` appendix (inventory). If unknown, stop and ask. Do not `SELECT *`. Do not guess UiPath table names.

## In scope

- `cmd/sync` (or `cmd/sync/main.go`): env `RPMP_SOURCE_DATABASE_URL` (required for this command), `RPMP_DATABASE_URL` (RPMP). Source role must be read-only in docs.
- Advisory lock so two syncs cannot run.
- Adapter reads source → domain → repo upserts. Idempotent on `source_key` / `source_ref`.
- Write `sync_runs` running → success/failure.
- CLI exit 0 on success, non-zero on failure. Log counts, not passwords or full source rows.
- Tests: fake source (testcontainers or SQL fixture of **RPMP-shaped** vendor subset once inventory exists).

## Out of scope

- Changing dashboard JSON. HTTP POST sync (BE-08). Frontend. Swagger. Production Orchestrator without inventory.

## Frozen contract

None for HTTP. Sync must fill tables so BE-07 can compute the same metrics as the stub grouping (success vs failure).

## Acceptance

- [ ] `go run ./cmd/sync` against local source + RPMP DSNs completes and inserts `sync_runs`.
- [ ] Vendor integers never stored as API-facing enums.
- [ ] Overlapping second sync is skipped or fails clearly.
- [ ] `go test ./...` pass. No frontend.
