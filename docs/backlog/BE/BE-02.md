## Frozen contract

`GET /api/v1/dashboard/summary`

Optional `from` and `to` are RFC 3339 timestamps. They must appear together and define `[from, to)`. When absent, use the trailing 30 days ending at request time.

Success is `200`:

```json
{
  "period": {
    "from": "2026-08-07T00:00:00Z",
    "to": "2026-09-06T00:00:00Z",
    "timezone": "UTC"
  },
  "freshness": {
    "status": "fresh",
    "last_successful_refresh_at": "2026-09-06T00:00:00Z"
  },
  "kpis": {
    "total_use_cases": 12,
    "active_use_cases": 9,
    "execution_volume": 100,
    "success_rate": 94.0,
    "failed_executions": 6
  }
}
```

`success_rate` is rounded to two decimal places and is `null` when volume is zero. Errors use the BE-01 `{ "code", "message" }` shape. Known codes are `invalid_period`, `unauthenticated`, `forbidden`, `source_unavailable`, and `internal_error`.

Stub-only meanings:

- Success is normalized fixture status `success`.
- Failure is normalized fixture status `failure` or `exception`.
- Active is current RPMP fixture status `active`.
- Execution Volume counts fixture executions starting in `[from, to)`.

These meanings are deterministic test definitions, not certified KRIs.

## Acceptance

- [ ] Viewer and Admin receive the frozen response shape; unauthenticated requests return `401`.
- [ ] Both or neither period parameters are accepted; malformed or reversed periods return `400 invalid_period`.
- [ ] The default period is a trailing 30-day half-open interval.
- [ ] Total and Active Use Cases are derived from registered fixture use cases.
- [ ] Execution Volume, Success Rate, and Failed Executions use the same requested period.
- [ ] Failure includes fixture `failure` and `exception`.
- [ ] Zero volume returns `success_rate: null`, never a divide-by-zero value.
- [ ] Fixture freshness is source data, not browser render time.
- [ ] Stub parsing stays in `internal/adapter`; the usecase receives RPMP terms.
- [ ] A typed source failure maps to `503 source_unavailable` without leaking adapter details.
- [ ] No fixture or aggregate persistence is added.
- [ ] Formatting, unit/integration tests, race tests, and `go vet` pass.
